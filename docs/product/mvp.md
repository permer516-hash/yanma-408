# MVP 范围

## 第一阶段

- 学习仪表盘：已实现
- 题库浏览、搜索、分页与筛选：已实现
- 单选题刷题：已实现
- 综合题答案与解析展示：基础数据结构已支持，完整在线判题暂缓
- 错题本与复习队列：已实现
- 真题套卷入口、整卷作答、报告与历史：已实现
- 学习分析基础面板与独立页：已实现
- 管理后台基础框架、题目维护、导入预校验：已实现
- 登录注册、服务端退出登录、密码重置、登录限流、审计日志与 token 管理：已实现
- 本地发布准备、PostgreSQL 回归脚本、发布前检查和基础 E2E：已实现
- 通知渠道偏好与多渠道通知记录：已实现
- 审核备注、基础审核权限约束和轻量富文本编辑体验：已实现
- 套卷报告总览、趋势分析和错题回灌：已实现
